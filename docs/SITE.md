# 官网定位与范围（SITE）

> 本文为后续开发者（含 AI 会话）提供站点上下文。范围或技术决策变化时同步更新本文件。

## 是什么

鸿枢 / Hongshu 的产品官网与下载入口：介绍产品、说明部署与隐私边界、提供下载入口与文档链接，
并作为搜索引擎与 AI 工具的可引用入口。站点与产品仓库分离：

| 事项 | 归属 |
| --- | --- |
| 产品功能、版本、发布资产、产品文档、Android/Web 客户端 | 产品仓库 `IGNGserver/hongshu` |
| 页面、样式、静态资源、SEO、站点文案 | 本仓库 |

注意：产品仓库内置的 `web/` 目录是产品自带的 Web/PWA 客户端；本仓库是独立的官网（产品站与下载入口），
两者不是一回事，不要把产品客户端代码复制到这里。

## 内容原则

- 只陈述产品仓库当前支持的事实，不编造路线图；版本与平台矩阵以产品仓库 `README.md` 为准；
- 产品边界必须如实呈现：首版只收件/查看，不发送短信，不处理 MMS/RCS，不提供端到端加密；
- 下载链接指向产品仓库的 Releases（正式签名 Android 安装包 `hongshu-*-android.apk`），不在本仓库托管安装包；
- 不展示任何真实短信内容、号码或个人数据（截图与示例必须脱敏）；
- 品牌名遵循产品仓库规范：显示"鸿枢（Hongshu）"。
